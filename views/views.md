# Views

This directory contains the main top-level components that represent a specific "page" or "view" within the application.

## View List

- **`CubicBezierView.tsx`**: The complete view for the interactive cubic-bezier editor. It includes the curve editor, filter controls, and the gallery of easing functions.
- **`GSAPView.tsx`**: A complete workspace for GSAP. It includes the advanced, multi-point curve editor for creating `CustomEase` functions, along with a filterable gallery to explore and compare all standard and custom GSAP eases.
