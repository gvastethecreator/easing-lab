# EASY EASING

**EASY EASING** es una herramienta profesional de visualización y creación de funciones de aceleración (easings) para desarrolladores web y diseñadores de UI. Permite explorar, editar y exportar curvas de animación tanto estándar (CSS Cubic Bezier) como avanzadas (GSAP CustomEase).

## 🚀 Características Principales

*   **Editor de Cubic Bezier:** Manipulación intuitiva con historial de cambios (Undo/Redo).
*   **Editor Multipunto (GSAP):** Creación de curvas complejas con múltiples puntos de anclaje.
*   **Galería Visual:** Colección curada de presets clasificados.
*   **Previsualización en Tiempo Real:** Visualización simultánea de movimiento, escala, rotación y escalonamiento.
*   **Arquitectura Robusta:** Sincronización de animaciones vía `gsap.ticker` fuera del ciclo de React.
*   **Diseño Modular:** Componentes reutilizables y layout composable.

## 🛠 Tecnologías

*   **Core:** React 19, TypeScript.
*   **Animación:** GSAP 3.12 (Core, MotionPathPlugin, CustomEase).
*   **Estilos:** Tailwind CSS.
*   **Build:** Vite.

## ⚡️ Instalación y Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/tu-usuario/easy-easing.git
    ```
2.  **Instalar dependencias:**
    ```bash
    npm install
    ```
3.  **Iniciar servidor de desarrollo:**
    ```bash
    npm run dev
    ```
