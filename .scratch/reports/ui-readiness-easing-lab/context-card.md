# UI context card

- Surface: single-page easing editor.
- User mode: explore presets, edit curves, compare motion, and copy code.
- Main artifact: curve editor with a live preview.
- Inputs: pointer, keyboard, and touch.
- Required widths: desktop and narrow mobile.
- Required themes: light and dark.
- Preserve: current layout, tokens, editor flows, and visual design.
- Costly states: complete routed views, engine loading/error, mobile menu, reduced motion, WebGL failure, and theme changes.

Proof files live under `proof/` and use matching routes and viewports for before/after checks.
