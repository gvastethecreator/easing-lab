# Triage fields

Local issue files use one category and one status field.

## Categories

| Canonical category | Local value   | Meaning                                 |
| ------------------ | ------------- | --------------------------------------- |
| `bug`              | `bug`         | Existing behavior is wrong or broken.   |
| `enhancement`      | `enhancement` | A needed improvement or new capability. |

## Statuses

| Canonical status  | Local value       | Meaning                                          |
| ----------------- | ----------------- | ------------------------------------------------ |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation is required.               |
| `needs-info`      | `needs-info`      | Work waits for missing information.              |
| `ready-for-agent` | `ready-for-agent` | The work is specified and ready for an agent.    |
| `ready-for-human` | `ready-for-human` | The work needs human implementation or judgment. |
| `wontfix`         | `wontfix`         | The work is deliberately not actioned.           |
